The 21 vendored SVG files in this directory are unmodified copies, each
with an upstream URL and SHA-256 in source_manifest.json. Adjacent
assets/icons/*.rgba8.z masks and preview PNGs are machine-generated
derivative rasterizations at 128x128. No network access is used at runtime.

hud_symbol is the existing UMS input/action identifier; blender_icon is the
Blender official art identifier. Existing geometry fallback is retained for
unsupported GPU backends.
