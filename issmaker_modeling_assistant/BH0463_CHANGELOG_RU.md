# ISSMAKER — BH-04B.6.3 TEST

Единый проход оформления «ГЕОМЕТРИЯ» и UV Seam Inspector. Красные и жёлтые фильтры, единый матовый интерфейс, статусы/навигация, общий lifecycle. Старые функции сохраняются, single-tile алгоритм и UV Wall не изменены.

Установить ZIP как Blender Add-on (не распаковывать). Перезапустить Blender. Для дополнительной проверки запустить AUTO TEST BRICK HOLE → ZIP и отправить сгенерированный диагностический архив.

Важное ограничение: ни GPU/HUD интерфейс, ни новая версия не были протестированы настоящим Blender в процессе подготовки этого ZIP. Это тестовый кандидат, а не принятый релиз.
