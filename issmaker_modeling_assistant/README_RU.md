# ISSMAKER Unified Modeling Suite 2.0.0

Версия 2.0.0 на основе исправленной 1.8.8.83.

- Исправлены реальные зоны нажатия кнопок ресурсов. Список материалов открывается и назначает выбранный материал с обновлением стены.
- Enter открывает отдельный HUD сглаживания в стиле ISSMAKER: точный ввод угла, пресеты 30/45/60/90°, отмена, применение.
- Smooth by Angle применяется к Mesh. Временный модификатор удаляется. Очищаются custom split normals; остальные выделенные объекты не затрагиваются. UV сохраняются точно, включая дополнительные UV-карты.
- Нижняя кнопка «Геометрия / качество» удалена. В круговом меню инструментов рядом со «Стилем» добавлена «Геометрия».
- Новый HUD геометрии: вкладки «Проверки», «Вид», «Сглаживание». Окно можно перемещать за заголовок и закрывать крестиком/Esc. При слишком маленькой области выводится понятное сообщение.
- Поиск Flip UV и аудит островов используют общую проверку по фактическим треугольникам Blender с контролем направления UV по формуле ZenUV. Смешанные/перекрещенные UV не объявляются однозначно зеркальными. Отрицательный масштаб объекта сам по себе не считается Flip UV. Поиск не изменяет координаты UV.
- Исправлены альфа-смешивание заливок HUD после отрисовки текста и единицы угла между интерфейсом и операторами Blender.
- Исправления геометрии и UV предыдущей версии сохранены. Геометрический алгоритм построения в этой итерации не менялся.

Установка: Preferences → Add-ons → Install from Disk → ZIP версии 2.0.0. Используйте чистую замену предыдущей версии и перезапустите Blender после установки. Не объединяйте папки разных версий.

Из установочного пакета исключены тесты, тестовые фикстуры, кэши Python, исторические отчёты и манифесты прошлых версий. Рабочие модули, графические ресурсы и текущие проверки целостности сохранены.

Проверено в Blender 4.5.5 LTS: фоновая матрица, реальные клики по списку материалов, назначение материала, окно угла и применение, открытие HUD геометрии из кругового меню, смена вкладки/угла и применение сглаживания. Полная матрица HiDPI, всех рабочих пространств и всех инструментов Suite не заявляется.
