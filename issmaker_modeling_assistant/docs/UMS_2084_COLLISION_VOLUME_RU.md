# UMS 2.0.84 — исправление Collision Inspector

Реальные геометрические проверки в Blender 5.2.4 LTS.
Проблема: при положительном объёмном пересечении совпадающих
по плоскостям выпуклых оболочек не регистрировался INTERSECTION.

Изменения:
- Положительный объём замкнутых выпуклых оболочек проверяется SAT
  по нормалям граней и перекрёстным направлениям рёбер.
- Копланарное перекрытие остаётся отдельным SURFACE_OVERLAP.
- Реальные касания, в том числе после поворота, не классифицируются
  как проникновение только по BVH-треугольникам.
- Валидация плоскостей граней, допуски float32 и лимит сложности
  исключают ложную уверенность на непроверенной геометрии.
- Невыпуклые оболочки используют прежний алгоритм: полноценная
  универсальная объёмная диагностика для них ещё не гарантирована.

Ограничения:
- Отдельные испытания Blender 4.5/4.x и макOS не проведены.
- Для сложной геометрии, превышающей бюджет SAT, остаётся
  прежний fallback (не все случаи проникновения могут быть распознаны).
- Для гарантированного применения обновления нужен перезапуск Blender.
