# ISSMAKER Unified Modeling Suite

Исходный код установленного пакета **UMS 2.0.84** для Blender, синхронизированный с локальным расширением Blender 5.2.4 LTS (15 ноября 2026 года).

## Инструменты

- **UV Wall** — параметрические стены, поверхности и карнизы. Единственный актуальный режим интерфейса: **Floating Pro**.
- **Collision Inspector** — диагностика пересечений геометрии.
- Общие инструменты моделирования и интерфейсные компоненты находятся в каталоге `issmaker_modeling_assistant/`.

## Проверки

- **268/268** Python-файлов прошли синтаксическую компиляцию.
- **207/207 PASS**, 0 FAIL, ERROR и SKIP — отдельный Blender 5.2.4 LTS с корректной регистрацией и снятием регистрации аддона.
- **60/60 PASS** тематических тестов в работающем Blender; контролируемые параметры рабочей сцены не изменились.
- Интерактивные действия мышью в HUD: **NOT_TESTED**. Автоматические тесты не заменяют полноценную визуальную приёмку.
